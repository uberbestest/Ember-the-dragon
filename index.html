Ember

A local browser micro-auditor for quick trainer-style review of a plan, prompt, or AI workflow note.

  • Flags proxy-heavy language such as score, speed, retention, and engagement.
  • Checks whether an objective and constraint are visible.
  • Saves and exports review notes locally in the browser.

Cass-V Lite

A deterministic command-line evaluator that returns the same report sections every time for reproducible review.

  • Extracts objective, constraints, proxies, and failure surfaces.
  • Marks invariant pass/fail with confidence.
  • Outputs a minimal repair tied to the original objective.

OUL

Objective Under Load is a small local CLI for checking whether an objective remains recoverable under optimization pressure.

  • Names the objective, load condition, constraints, and observed drift risk.
  • Classifies pressure as preserved, stressed, drifting, proxy-substituted, or collapsed.
  • Returns a repair recommendation and commit summary without model calls.

Short Usage Examples

Ember input

Objective: Help support agents answer accurately.
Constraint: Keep cited source policy visible.
Measure success by faster handling time and higher completion volume.

OUL command

python -m oul.cli --file examples\oul_proxy_substitution_input.txt

Cass-V Lite command

python cass_v_lite.py "Objective: Keep AI assistant answers source-grounded. The workflow must preserve escalation rules. Measure success by response speed and user satisfaction score."

The expected repair is plain: treat speed, score, and satisfaction as monitoring signals only, then bind evaluation back to source-grounded answers and escalation rules.
