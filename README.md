# Ember

Tiny local drift-check companion for catching when a plan, prompt, repo task, or product idea stops solving the original problem.

Ember is a single-file browser tool. It runs locally in your browser, stores hoarded notes only in local storage, and does not send input anywhere.

## Use

Open:

```text
ember-desk-dragon.html
```

Then paste a thought, plan, title, prompt, or suspicious objective and run either:

- `Smell Test` for a quick proxy/drift sniff.
- `Rin Check` for a slightly more structured status read.

## Sprite Assets

```text

```

Canonical runtime asset:

```text
assets/ember-v2-20260709/spritesheet.webp
```

The same folder preserves audit artifacts, including the manifest, pet request, validation result, contact sheet, look-direction sheet, despill report, direction semantics, continuity report, and run summary.

The previous repo visual state was the inline dragon emoji in `ember-desk-dragon.html`; that state remains preserved in git history and is noted in `assets/archive/README.md`.

## Boundary

Ember is not a judge, oracle, chatbot, planner, or alignment authority. It is a small local smell-test surface for keeping the original objective visible under pressure.
