# Ember

A tiny desk dragon that runs a simple "smell test" on ideas.

Drop in a thought, plan, or prompt. Ember will occasionally tell you if you're optimizing the wrong thing.

No accounts. No tracking. Just a small loop for catching drift early.

## Use

Open ember-desk-dragon.html in a browser.
If GitHub Pages or another static host serves the repository root, index.html will launch Ember automatically.

## Files

- `ember-desk-dragon.html` - the standalone desk dragon app
- `index.html` - a small launcher/redirect for static hosting

## Notes

Ember is intentionally self-contained: plain HTML, CSS, and JavaScript with no build step.
